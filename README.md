# 車両カタログ（GitHub Pages）

## Googleスプレッドシートとの接続

このサイトは、GoogleスプレッドシートからCSV形式でデータを取得し、ブラウザー上に表示します。現在は、リンク先スプレッドシートの先頭のシート（`gid=0`）を読み込む設定です。

スプレッドシートの共有設定を **「リンクを知っている全員」—「閲覧者」** にしてください。Google Workspaceの組織設定などでCSV形式の取得が制限されている場合は、Googleスプレッドシートの **「ファイル」→「共有」→「ウェブに公開」** を開き、対象のシートと **「カンマ区切り形式（.csv）」** を選んで公開してください。その公開CSVのURLを `app.js` の `SHEET_CSV_URL` に設定します。

別のシートを読み込む場合は、`app.js` のURLにある `gid=0` を、対象シートのURLに表示される数値の `gid` に変更してください。

## 列の読み取り

見出し行がない場合でも、A列を車名、B列を価格として読み込みます。1行目に「車名」と「価格」の見出しがある場合は、見出しを自動判別して読み込みます。

カテゴリ・画像・販売場所も表示する場合は、任意の列に「カテゴリ」「画像」「販売場所」の見出しを付けてください。画像列には、ブラウザーから閲覧できる画像URLを入力します。認識する見出しの別名は `app.js` の `FIELD_MAP` に記載されています。

カテゴリ列には「普通車」「高級車」「航空機」「ボート」のいずれかを入力してください。カテゴリ列がない場合、車名からカテゴリを推定しますが、正しく分類するにはカテゴリ列の追加をおすすめします。販売場所が空欄の場合は、`app.js` の `DEFAULT_LOCATION` に設定された一般的な名称を表示します。実際の販売場所を表示するには、シートに販売場所を入力するか、`DEFAULT_LOCATION` を編集してください。

## GitHub Pagesでの公開

このフォルダー内のファイルをGitHubリポジトリのルートに置くか、GitHub Pagesの公開元として `outputs` フォルダーを指定し、リポジトリの設定でGitHub Pagesを有効にしてください。

タブに表示する「普通車（200）」「高級車（670）」「ボート（356）」の数字は、`app.js` の `CATEGORIES` で設定しています。航空機の数字は、シートから読み込んだ該当データの件数を表示します。

## 件数表示について

タブの括弧内に表示する数字は、ご指定の値を表示する設定です。実際のシート上の件数に合わせる場合は、`app.js` の `CATEGORIES` にある各カテゴリの `count` を変更してください。タブを選択したときの絞り込みは、シートから読み込んだデータを使って行います。
